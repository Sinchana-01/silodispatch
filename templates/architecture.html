SiloDispatch - System Architecture

🔧 Tech Stack

  • Backend: FastAPI (Python)
  • Database: PostgreSQL (via SQLAlchemy ORM)
  • Frontend: Plain HTML + Jinja2 templates
  • Payment: Razorpay (UPI/COD/prepaid)
  • OTP Delivery: AWS SNS
  • Tracking: Simulated GPS Breadcrumbs

🔁 Modules Overview

1. Order Intake

  • Upload 500 orders via CSV or API
  • Fields: amount, payment_mode, address, lat/lng, etc.

2. Order Clustering & Batch Creation

  • KMeans clustering by lat/lng
  • Each batch capped at 25kg or 30 orders
  • Stored in `batches` table

3. Driver Assignment

  • Drivers stored in `drivers` table
  • Auto-assign nearest available driver based on centroid location
  • Manual fallback via form

4. OTP & Payment Flow

  • OTP sent via AWS SNS
  • Supports COD, Prepaid, and Razorpay UPI links
  • Webhook confirms UPI success

5. Settlement & Reporting

  • Live driver-wise COD totals (based on `orders`)
  • One-click settle posts into `settlements` table
  • CSV export for finance

🗃️ Database Relations (Short Summary)

  • Order: Links to driver and batch
  • Batch: Contains clustered order list
  • Driver: Gets assigned batches
  • Settlement: Records cash reconciliation
  • Breadcrumb: (Optional) Location tracking
