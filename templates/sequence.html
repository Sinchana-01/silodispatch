Sequence Diagram - Order to Delivery Flow

Steps in the Sequence

  • Customer places an order via API or frontend.
  • System validates OTP and confirms payment (COD/UPI/Prepaid).
  • Batching logic runs and clusters orders based on weight/pincode/location.
  • Driver is assigned automatically or manually via UI.
  • Delivery happens; COD payments are collected and status updated.
  • Settlement dashboard shows cash owed by each driver for reconciliation.
